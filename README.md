# zMail

An AI-first mail client for macOS: Gmail and Microsoft 365 in one window, sorted for you, with an assistant that reads, files and drafts.

## Download

Get the DMG from the [latest release](https://github.com/umzcio/zMail/releases/latest), open it and drag zMail to Applications. It's signed and notarized by Apple. Apple silicon Macs only for now.

zMail updates itself: it checks for a new version shortly after launch and once a day after that, and installs one only when you say so. Updates are signed, and zMail won't install one that isn't.
